# FlowOE experiment analysis

This report covers synthetic market simulations generated by scripts/run_analysis_suite.py. It is intended for model-development, regression, and execution-mechanics analysis. It is not a substitute for the real-market evidence run.

## Coverage

- Regimes: 7
- CFM seed fits: 20
- Schedule-family evaluations: 35
- Sampling-step settings: 6
- Quantity settings: 5
- Probability-flow ODE comparison: 1 paired regime
